## 🛠️ 部署说明

* **环境要求：** PHP 7.3+，需启用 `curl`、`json` 扩展；`txt2m3u` 为纯静态页面无需 PHP。
* **安全配置：** 复制 `lib/config.sample.php` 为 `lib/config.php` 后按需修改（跨域白名单、访问密钥、限流、内网访问、证书校验）。`config.php` 请勿提交到公开仓库。
* **局域网自用：** 若 SOCKS5 代理或直播源在内网，把 `allow_private` 设为 `true`。
* **Nginx 用户：** `.htaccess` 不生效，请额外添加：
  ```nginx
  location ~ ^/(lib|socks5/cache)/ { deny all; }
  ```
* **部署自检：** 上传后访问一次 `/selfcheck.php`，确认全部通过后删除该文件。
* **台标索引：** `LOGO/logos.json` 列出全部台标的尺寸、MD5 及内容相同的别名（`same_as`）。
* 文件名含空格或 `&` 的台标，在 m3u 中引用时需要 URL 编码（例如空格写成 `%20`）。
