## 🟡 图片质量问题
- `TVBL.png`、`MTVBLOCKPARTY.png`：浅灰色加透明底，在浅色背景上几乎看不见。
- `八大综合.png`（107×18）、`八大戏剧台.png`、`八大第一.png`：分辨率过低。

## ✅ 核对后确认没问题（举例）
- 安徽 `ANHUI1~6` 和中文名、`BTV*` 和 `BRTV*`、`iHOT*` 和 `爱*`、`NewTV*` 系列、繁简体对照：都是正常别名。
- `j5` = 无线财经资讯台（J5 已改名）、`CCTV7.CN` = CCTV-7 国防军事：都正确。
- `SPECIALEVENTSPORTS01~09` 用的是 Astro 奥运转播台标，属于赛事专用台，可以接受。
