# 网页优化说明（企业级 + 电脑端 / 移动端适配）

## 统一界面增强层（所有页面共用）
- `assets/ui.css`：只做增强，不改原有布局和配色（选择器优先级为 0，页面自身样式优先）
- `assets/ui.js`：无依赖，约 7KB，在各页面 `<head>` 中引入

| 能力 | 说明 |
|---|---|
| 键盘可访问 | Tab 键焦点高亮；"跳到主要内容"链接；只有图标的按钮、无标签的输入框自动补充无障碍名称 |
| 统一导航 | 各工具页顶部加"← 工具箱"返回入口（播放器放在顶栏按钮组里） |
| 轻提示 | `alert()` 改为非阻塞的轻提示，自动消失、可关闭；`confirm()` 保持原生，不影响流程 |
| 回到顶部 | 长页面滚动超过 600px 时出现 |
| 生产环境静默 | 关闭 `console.log`，地址后加 `?debug=1` 可恢复；warn / error 保留 |
| 减少动效 | 跟随系统"减弱动态效果"设置 |
| 打印 | 隐藏按钮，外链后显示网址 |

## 移动端
- **允许双指缩放**：去掉 `user-scalable=no` / `maximum-scale=1`（原设置违反无障碍规范，视力不好的用户无法放大）；同时用 `touch-action: manipulation` 去掉双击放大和 300ms 点击延迟
- **iOS 输入框不再自动放大页面**：小屏下输入框字号统一为 16px
- **刘海屏 / 横屏安全区**：工具页和播放器都按 `safe-area-inset` 留白
- **播放器高度**：`100vh` 改为 `100dvh`，地址栏收起或展开时，全屏层不再被遮挡或露出空隙
- **触控尺寸**：触屏设备上按钮不小于 40px（播放器视频内的控件不受影响）
- **表格**：自动包进横向滚动容器，宽表格不再撑破页面
- **长链接**：直播源地址、日志等长文本自动换行
- **修复溢出**：val 页面右侧面板 `min-width:400px` 在 360px 宽的手机上会横向溢出，已修复
- 禁止 iOS 把 IP、端口等数字自动识别成电话号码

## 电脑端
- 超宽屏（≥1680px）内容区放宽到 1560px
- 细滚动条、键盘焦点样式
- 首页按 `/` 键聚焦搜索框，按 `Esc` 清空

## 各页面
- **首页**：
  - 补上原本为空的副标题
  - 删除写着"占位符"的"更多功能筹划中"卡片
  - 新增工具搜索（支持多关键词）
  - 外部工具（TVBox 解密）标注"外部站点"
  - 页脚年份自动更新
- **404**：重写为独立页面，不依赖其它文件
  - 字号随屏幕自适应，小屏下按钮纵向排列
  - 支持深色模式和减弱动效
  - 显示用户访问的路径，提供"返回工具箱""返回上一页"和常用工具链接
  - 设置 `noindex`，不被搜索引擎收录
- **全部页面 `<head>`**：
  - 补充 description（便于搜索与分享）、theme-color（浅色 / 深色）、format-detection
  - 预连接外部 CDN，加快首屏加载
  - 增加 `<noscript>` 提示

## 站点配置
- `.htaccess`（Apache）/ `docs/nginx.conf.example`（Nginx）：
  - 安全响应头：nosniff、X-Frame-Options、Referrer-Policy、Permissions-Policy
  - 内容安全策略（CSP）：先用"仅报告"模式，确认浏览器控制台没有违规后再改为强制
  - 台标长缓存并允许跨域引用；HTML 不缓存
  - 开启 gzip；禁止列出目录；屏蔽敏感文件；404 指向 `404.html`

## 未改动 / 需人工确认
- 各工具原有的配色和布局没有重新设计，以免改坏现有功能
- 我这边无法打开浏览器，**以上效果没有实际截图验证**，请在电脑和手机上各打开一遍确认

# 第二轮：企业级视觉与布局统一（assets/theme.css）

## 接入方式
- 新增 `assets/theme.css`，各页面在 `ui.css` 之后引入；`ui.js` 的 `data-page` 属性在 `<head>` 阶段写到 `<html>` 上，样式无闪烁生效
- 只改视觉和布局，**不改任何 id / class / 接口逻辑**；删掉 theme.css 的 `<link>` 即可回到旧样式
- 改动前的 HTML/CSS/JS/PHP 已备份到 `backup-ui-20261123-0033/`

## 设计规范（全站统一）
| 项目 | 规范 |
|---|---|
| 主色 | 统一品牌蓝 #2563eb（原来各页蓝 / 紫 / 绿混用） |
| 语义色 | 成功 / 警示 / 危险 / 信息 各一套"实色 + 浅底 + 描边 + 文字色"，深色模式单独调过 |
| 圆角 | 6 / 8 / 10 / 12 / 16px 五档（原来 4px~20px 混用） |
| 阴影 | xs / sm / md / lg 四档，克制使用 |
| 控件高度 | 常规 38px、紧凑 32px；触屏 44px |
| 字号 | 正文 14px，辅助 12.5~13px，面板标题 15px，页面标题 22px |
| 间距 | 4 的倍数；面板内边距 20px，区块间距 20px |

## 按钮层级
- **主要**（实色蓝）：发送请求、开始扫描、完整测试、开始测试、TXT转M3U
- **描边主色**：仅验证代理、M3U转TXT
- **成功**（实色绿）：下载
- **次要**（白底描边）：填充示例、导出、复制、加载示例、上传文件、重新分组等
- **柔和警示 / 柔和危险**（浅色底）：暂停 / 停止、清除
- 去掉悬停上浮，改为阴影与底色变化；按钮内图标统一间距

## 弹窗 / 提示
- **确认对话框**：11 处原生 `confirm()` 改为站内对话框（图标 + 标题 + 说明 + 操作按钮），支持 Esc 取消、Tab 切换焦点、点遮罩关闭；删除 / 清空类操作自动显示红色"确认清除 / 确认删除"，默认焦点停在"取消"上，防止误操作；手机上按钮纵向全宽排列
- **轻提示**：白底卡片 + 左侧色条 + 图标，按内容自动识别"成功 / 警示 / 错误 / 信息"四种类型
- 对外接口：`uiConfirm(msg, {title, okText, cancelText, danger})` 返回 Promise；`uiToast(msg, ms, type)`

## 胶囊 / 徽标
- 状态徽标（200 / 504 / 代理错误 / 测试中 / 失败）统一为浅底胶囊，不再用大块实色
- 标签页计数、记录数、分组名、代理地址等统一为中性或主色浅底胶囊
- 首页卡片标签改为中性胶囊，颜色只保留在图标上；"外部站点"用警示色胶囊

## 布局
- 工具页页头改为左对齐：渐变图标块 + 标题 + 副标题，下方细分隔线；"← 工具箱"改为胶囊按钮
- 面板：统一白底、1px 描边、12px 圆角；面板标题加浅色图标底
- 标签页：下划线式，激活态主色，悬停浅底
- 列表行（历史、结果、记录、代理卡片、频道）：取消悬停位移，改为描边变色；结果用 3px 左侧色条区分有效 / 超时 / 无效
- 指标：响应信息改为小卡片；val 页统计块改为数据卡（大号数字 + 小标签）
- 表格：表头浅底、行悬停高亮；日志 / 代码区统一等宽字体和浅底
- **txt2m3u**：去掉整页大卡片 + 渐变页头，改成和其它工具一致的卡片布局；6 个操作按钮从一行彩虹色改为 3 列网格（手机 2 列），主次分明
- **首页**：页头改为带柔和光晕的卡片，搜索框、卡片间距、标题字号重新调整
- 播放器：只做令牌级微调（主色、顶栏毛玻璃、抽屉描边、状态胶囊），视频控件尺寸不动

## 发现并修复的问题
1. **val**：HTML 嵌套错误，"测试日志"面板跑出了底部容器、页脚跑出了页面容器，导致记录和日志无法并排；已修正
2. **val**：页脚标题写成了"SOCKS5代理直播源测试工具"；已改为"直播源有效性验证工具"
3. **resp/style.css**：文件中混入了一段"[file name]: style.css [file content begin]"文本，导致紧随其后的"代理错误"状态样式失效；已删除
4. **player / player2**：两个页面标题和顶栏名称都叫"视频播放器"，无法区分；已分别改为"直播源播放器""增强版直播播放器"
5. **5 个工具页页脚**：年份写死 2025；改为自动显示当前年份
6. **socks5**："仅验证代理"按钮写死了行内蓝色，无法跟随主题；已移除
7. **旧样式硬编码蓝色**：各页面旧样式里写死的蓝色（共 61 处）改为跟随页面主色，不再出现蓝色残留
8. **socks5 深色**：旧样式里的浅色块（标签内容区、记录时间、统计框、滚动条轨道、脚本生成的灰字）统一改为深色，避免白块
9. **响应式**：各页电脑端改为网格分栏（之前靠 flex + 固定 min-width，平板宽度下容易挤压或溢出），移动端统一单列并调整按钮排列
