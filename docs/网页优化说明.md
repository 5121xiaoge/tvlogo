# 网页优化说明（企业级 + 电脑端 / 移动端适配）

## 统一界面增强层（所有页面共用）
- `assets/ui.css`：只做增强，不改原有布局和配色（选择器优先级为 0，页面自身样式优先）
- `assets/ui.js`：无依赖，约 7KB，在各页面 `<head>` 中引入

| 能力 | 说明 |
|---|---|
| 键盘可访问 | Tab 键焦点高亮；"跳到主要内容"链接；只有图标的按钮、无标签的输入框自动补充无障碍名称 |
| 统一导航 | 各工具页顶部加"← 工具箱"返回入口（播放器放在顶栏按钮组里） |
| 轻提示 | `alert()` 改为非阻塞的轻提示，自动消失、可关闭；`confirm()` 保持原生，不影响流程 |
| 回到顶部 | 长页面滚动超过 600px 时出现 |
| 生产环境静默 | 关闭 `console.log`，地址后加 `?debug=1` 可恢复；warn / error 保留 |
| 减少动效 | 跟随系统"减弱动态效果"设置 |
| 打印 | 隐藏按钮，外链后显示网址 |

## 移动端
- **允许双指缩放**：去掉 `user-scalable=no` / `maximum-scale=1`（原设置违反无障碍规范，视力不好的用户无法放大）；同时用 `touch-action: manipulation` 去掉双击放大和 300ms 点击延迟
- **iOS 输入框不再自动放大页面**：小屏下输入框字号统一为 16px
- **刘海屏 / 横屏安全区**：工具页和播放器都按 `safe-area-inset` 留白
- **播放器高度**：`100vh` 改为 `100dvh`，地址栏收起或展开时，全屏层不再被遮挡或露出空隙
- **触控尺寸**：触屏设备上按钮不小于 40px（播放器视频内的控件不受影响）
- **表格**：自动包进横向滚动容器，宽表格不再撑破页面
- **长链接**：直播源地址、日志等长文本自动换行
- **修复溢出**：val 页面右侧面板 `min-width:400px` 在 360px 宽的手机上会横向溢出，已修复
- 禁止 iOS 把 IP、端口等数字自动识别成电话号码

## 电脑端
- 超宽屏（≥1680px）内容区放宽到 1560px
- 细滚动条、键盘焦点样式
- 首页按 `/` 键聚焦搜索框，按 `Esc` 清空

## 各页面
- **首页**：
  - 补上原本为空的副标题
  - 删除写着"占位符"的"更多功能筹划中"卡片
  - 新增工具搜索（支持多关键词）
  - 外部工具（TVBox 解密）标注"外部站点"
  - 页脚年份自动更新
- **404**：重写为独立页面，不依赖其它文件
  - 字号随屏幕自适应，小屏下按钮纵向排列
  - 支持深色模式和减弱动效
  - 显示用户访问的路径，提供"返回工具箱""返回上一页"和常用工具链接
  - 设置 `noindex`，不被搜索引擎收录
- **全部页面 `<head>`**：
  - 补充 description（便于搜索与分享）、theme-color（浅色 / 深色）、format-detection
  - 预连接外部 CDN，加快首屏加载
  - 增加 `<noscript>` 提示

## 站点配置
- `.htaccess`（Apache）/ `docs/nginx.conf.example`（Nginx）：
  - 安全响应头：nosniff、X-Frame-Options、Referrer-Policy、Permissions-Policy
  - 内容安全策略（CSP）：先用"仅报告"模式，确认浏览器控制台没有违规后再改为强制
  - 台标长缓存并允许跨域引用；HTML 不缓存
  - 开启 gzip；禁止列出目录；屏蔽敏感文件；404 指向 `404.html`
