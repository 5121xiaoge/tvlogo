# 优化说明

## 安全
- 新增 `lib/security.php`（所有 PHP 接口在开头引入）+ `lib/config.sample.php`
  - 仅允许 http/https；直连时禁止访问内网/保留地址，跳转的每一跳都会重新校验；请求完成后再核对实际连接的 IP（可防 DNS 重绑定、hosts 映射到内网）
  - 代理地址不能是内网地址（`val` 手写 SOCKS5 握手前也做了校验）
  - 默认开启 HTTPS 证书校验（`ssl_verify` 可关闭）
  - `Access-Control-Allow-Origin: *` 改为可配置的白名单（默认仅同源）
  - 可选：访问密钥（Cookie 方式）、按 IP 限流
  - 统一加 `X-Content-Type-Options: nosniff`
- `player/player2 proxy.php`：改成手动跟随跳转；只透传安全的音视频/图片 Content-Type（图片不允许 SVG）
- `resp/api.php` 下载接口固定输出 `application/octet-stream`，并清洗文件名
- 日志改写到系统临时目录，默认关闭；删除 `resp/logs/proxy_debug.log`
- `socks5/ip_query.php`：删除 `?test_ip=` 调试入口；修复 IPv6 缓存文件名；`socks5/cache/` 禁止 Web 访问
- `socks5/样本.txt`：已脱敏 Authinfo、accountinfo、stbId 和签名参数
- 前端（resp/scan/socks5/val）：插入 innerHTML 的 URL、日志、文件名等全部转义，防 XSS
- 代理密码不再写入 localStorage 或历史记录（播放器改用 sessionStorage）

## 台标
- 98 个扩展名与实际格式不符的文件已转成扩展名对应的格式；`tv_logo_35.png`（实为 SVG）已改名为 `.svg`
- 448 张长边超过 512px 的图片已等比缩到 512px
- 全部无损重新压缩；1844 张做了 256 色量化（只有 PSNR ≥ 38dB 且体积减少 25% 以上才替换）
- 新增 `LOGO/logos.json` 索引；问题清单见 `docs/台标问题清单.csv`（重复文件、疑似放错、同名不同格式、特殊字符、低分辨率）
- 重复文件 **没有删除**（删掉会让已有的 m3u 链接失效），需按清单人工处理
- 删除已过期的 `LOGO/epg.xml`（2024-05 的节目单，代码中没有引用）

## 前端资源
- `hls.js`（1.47MB 开发版 ×2）换成 `player/hls.min.js`（同版本 1.6.13，0.54MB），player2 共用这一份

## 代码重构（第三轮）
- 新增 `lib/common.php`，统一了以前分散在 6 个接口里的重复函数：
  - URL 解析（`absolute_url` / `resolve_relative_url` / `resolveRelativeUrl` / `is_absolute_url` / `isAbsoluteUrl`）改为同一个 `url_resolve()`
  - `parseHeaders`、`returnJson`、`build_proxy_url`、`rewrite_m3u8`
  - 旧函数名全部保留为别名，调用方不用改
- 顺带修复 URL 解析的 4 个缺陷：
  - 基准地址以 `/` 结尾时（如 `http://h/live/`）会丢掉最后一级目录，导致分片 404
  - 在 Windows 服务器上，`dirname()` 返回反斜杠，拼出 `http://h\/a.ts`
  - player 把 `//cdn/x.ts` 拼成 `http://host//cdn/x.ts`
  - 地址为空字符串时报下标警告
- 去掉 PHP 文件末尾的 `?>`，避免多余空白混进视频流输出
- 6 个工具页的 Font Awesome（cdnjs 6.4.0）加了 SRI 完整性校验
- **没有合并 player 和 player2**：两者是不同的产品（单链接播放 vs 播放列表 + EPG + 多线路），`main.js` 只有约一半相同，CSS 几乎完全不同。强行合并很容易丢功能，建议保留两个入口

## 部署自检
- 新增根目录 `selfcheck.php`：上传后用浏览器访问一次，可以检查 PHP 环境和扩展、安全配置、链接解析与 M3U8 改写、内网地址拦截、敏感文件是否已清理，以及 `lib/` 是否禁止通过网页访问
- **检查完请删除 `selfcheck.php`**
